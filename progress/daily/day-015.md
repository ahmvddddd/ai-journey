## Lessons Learned

* **Inclusive vs. Exclusive Slicing:** Slicing with `.loc` includes both start and end boundary labels, whereas `.iloc` excludes the upper boundary integer index[cite: 10].
* **Block Manager Alignment:** Pandas groups contiguous columns of identical types into Block Managers, keeping numerical calculations close to native NumPy speed while adding labeled metadata safety[cite: 10].
