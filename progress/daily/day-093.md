## Lessons Learned

* **Resolution-Independent Parameter Scaling:** Unlike `nn.Linear`, whose weight matrix scales with $H \times W$, `nn.Conv2d` parameter counts depend only on `in_channels`, `out_channels`, and `kernel_size`, enabling translation-friendly feature extraction across arbitrary spatial dimensions.

* **Controlled Spatial Downsampling:** Using `padding=1` with $3 \times 3$ kernels preserves feature map height and width across stacked layers, while `stride=2` halves spatial dimensions to expand effective receptive fields in deeper stages.
