## Lessons Learned

* **Explicit Schema Enforcement:** Defining explicit data types during ingestion (`dtype=schema_dtypes`) prevents Pandas from defaulting to memory-heavy `object` dtypes.
* **Upstream Anomaly Simulation:** Deliberately injecting missing values and sentinel error codes (`-99`) during dataset creation ensures robust test coverage for subsequent data cleaning pipelines.
