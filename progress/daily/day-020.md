## Lessons Learned

* **Error Coercion:** Passing `errors='coerce'` to `pd.to_datetime()` safely replaces unparseable or corrupted date strings with `NaT` without breaking pipeline execution[cite: 19].
* **Selective Imputation Safety:** Numerical imputation (e.g., `fillna(median)`) should only be executed *after* invalid corruption markers (like `-999.0`) are replaced with `NaN`, ensuring baseline stats remain uncorrupted[cite: 19].
* **Modular Pipeline Architecture:** Encapsulating cleaning steps inside a single function (e.g., `clean_transaction_data(df)`) ensures reusability and clean testability[cite: 19].
