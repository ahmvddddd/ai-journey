## Lessons Learned

* **Composition over Inheritance:** Composing `InventoryItem` with `Product` keeps static product metadata separated from dynamic inventory quantities.
* **Encapsulation:** Using `@property` setters guarantees domain invariants (e.g., non-negative stock counts) across all operations.
* **Dataclasses:** `@dataclass` significantly reduces boilerplate code for data-holding classes while providing clean string representations (`__repr__`) and value equality comparisons out of the box.
