## Lessons Learned

* **Bitwise Precedence Rule:** Python evaluates bitwise operators (`&`, `|`) before comparison operators (`>`, `==`)[cite: 12]. Wrapping individual conditions in explicit parentheses (e.g., `(df['amount'] > 100) & (df['category'] == 'A')`) is required to prevent syntax/value errors[cite: 12].
* **Logical Operator Distinction:** Standard Python `and` / `or` evaluate truth values for an entire object, whereas Pandas requires bitwise `&` / `|` for element-wise array evaluation[cite: 12].
* **Variable Interpolation with `@`:** Using `@variable` inside `.query()` cleanly decouples filtering parameters from expression logic while avoiding string concatenation risks[cite: 12].
