## Lessons Learned

* **Zero-Parameter Spatial Compression:** Pooling layers add `0` trainable parameters while reducing spatial area ($H \times W$) by $4\times$ per $2 \times 2$ (`stride=2`) step, cutting downstream compute and expanding effective receptive fields in deeper layers.

* **Resolution-Agnostic Classifier Heads:** Pairing `nn.AdaptiveAvgPool2d((1, 1))` with `.flatten(1)` collapses each channel's spatial map into a single summary scalar, preventing massive flattened `nn.Linear` parameter counts and supporting arbitrary input resolutions.
