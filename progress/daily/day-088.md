## Lessons Learned

* **Dual Evaluation Safeguards:** `model.eval()` governs layer behavior (such as disabling `nn.Dropout` and freezing `BatchNorm` running statistics), while `torch.no_grad()` prevents autograd graph allocation; using both together ensures accurate, fast, and memory-efficient evaluation.
* **Conditional Model Checkpointing:** Saving `model.state_dict()` only when `val_rmse` beats `best_val_rmse` retains the strongest generalization weights during longer training runs and avoids overwriting superior intermediate checkpoints with overfitted late epochs.
