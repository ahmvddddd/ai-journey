## Lessons Learned

* **Strict Target Dtype Hygiene for Classification:** `nn.CrossEntropyLoss()` requires 1D target tensors of dtype `torch.int64` (`torch.long`) to index class log-probabilities directly; floating-point targets trigger runtime errors unless explicitly using soft-label cross-entropy.

* **Loss vs. Top-1 Accuracy Sensitivity:** Accuracy only evaluates the winning logit index (`argmax`), whereas cross-entropy loss penalizes probability calibration across all classes—making validation loss an essential early warning signal for overconfident errors and logit norm drift.
