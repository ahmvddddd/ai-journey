## Work Completed

Built a complete, zero-loop telemetry processing pipeline using NumPy:
* **Synthetic Data Simulation:** Generated multi-channel time-series data ($10 \times 5$) and injected extreme numeric outliers and missing data codes.
* **Vectorized Data Cleaning:** Isolated valid data ranges using combined boolean masks `(raw_data > 0) & (raw_data < 100)` to calculate clean medians, followed by in-place updates.
* **Broadcasting & Standardization:** Applied column-wise $Z$-score normalization (`(clean_data - mean) / std`) across all sensor readings simultaneously.

## Evidence

* Interactive telemetry pipeline executed cleanly in the workspace environment.

## Lessons Learned

* **Axis Alignment in Normalization:** Computing column-wise mean and standard deviation along `axis=0` allows seamless broadcasting across 2D matrices.
* **Boolean Index Safety:** Computing summary statistics (like median or mean) on subset arrays using boolean masks prevents bad inputs from corrupting baseline values.
