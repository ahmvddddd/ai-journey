## Lessons Learned

* **Index Management (`as_index=False`):** Passing `as_index=False` keeps grouping keys as regular columns, preventing index resetting overhead and simplifying downstream ML pipeline integration[cite: 16].
* **`.agg()` vs `.transform()`:** `.agg()` collapses groups into summary scalars (reducing row count), whereas `.transform()` calculates group metrics and broadcasts them back to every original row[cite: 16].
* **Z-Score Feature Normalization:** Using `(df['val'] - df.groupby('cat')['val'].transform('mean')) / df.groupby('cat')['val'].transform('std')` scales features relative to group baselines efficiently[cite: 16].
