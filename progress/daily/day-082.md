## Lessons Learned

* **Scalar Backward Requirement:** `.backward()` expects a scalar loss tensor by default with an implicit upstream gradient of `1.0`, traversing the computation graph backward via the chain rule.

* **Training Loop Gradient Hygiene:** Always clear accumulated gradients (`optimizer.zero_grad()` or `.grad.zero_()`) each iteration so stale gradients from prior batches do not corrupt weight updates.
