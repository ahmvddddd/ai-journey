## Lessons Learned

* **Categorical Efficiency:** Specifying `dtype={'col': 'category'}` for high-cardinality/repeated text columns avoids Python object pointer overhead and drastically minimizes RAM usage[cite: 11].
* **Global Mean via Streaming:** When averaging across chunks, never average chunk-level means directly; accumulate running sums (`sum()`) and total valid counts (`count()`) across iterations[cite: 11].
* **Nested JSON Structuring:** Passing `record_path` extracts nested array elements as individual rows, while `meta` duplicates parent metadata across those rows seamlessly[cite: 11].
